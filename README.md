# ScrumArt — модуль Scrum

Веб-сервис для небольших студий видеопродакшена: продюсер ведёт бэклог проекта, планирует спринты, а режиссёр, оператор и монтажёр видят свои задачи на Scrum-доске.

Стек: Node.js 20 + Express 4.21.2, страницы рисует шаблонизатор EJS 3.1.10. Один контейнер, без отдельной БД — демо-данные хранятся в памяти (`data/project.js`).

## Запуск

```bash
docker pull nikitavrazhkin/mispisit-lab1:0.0.2
docker run --rm -p 8080:8080 nikitavrazhkin/mispisit-lab1:0.0.2
```

После запуска открыть http://localhost:8080

## Страницы и функции (ЛР2)

| Адрес | Что на странице |
|---|---|
| `/` | Главная: текущий спринт, загрузка, переходы ко всем действиям |
| `/tasks/new` → `POST /tasks` | Создание задачи в бэклоге (пустое название или оценка не из шкалы Фибоначчи — форма с ошибками) |
| `/backlog` → `POST /backlog/:id/to-sprint` | Просмотр бэклога и перенос задачи в спринт |
| `/sprint` → `POST /sprint/tasks/:id/next` | Scrum-доска спринта, перевод задачи в следующую колонку |
| `/sprint-overload` | Отказ: задача не помещается в спринт — превышена ёмкость команды |

Проверка отказа: в бэклоге нажать «В спринт 3» у задачи «Цветокоррекция финальной версии» (5 SP) — в спринте уже 18 из 21 SP.
Успешный перенос: «Сведение звука и голос диктора» (3 SP).

## Структура

```
server.js              запуск Express, шаблонизатор EJS, главная, 404
routes/backlog.js      бэклог, создание задачи, перенос в спринт
routes/sprint.js       Scrum-доска, смена статуса, страница отказа
views/partials/        header.ejs (меню), footer.ejs (версия)
views/*.ejs            index, backlog, task-new, sprint, sprint-overload, not-found
data/project.js        демо-данные проекта в памяти
public/style.css       стили
```
