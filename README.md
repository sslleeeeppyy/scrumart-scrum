# ScrumArt — модуль Scrum

Веб-сервис для небольших студий видеопродакшена: продюсер ведёт бэклог проекта, планирует спринты, а режиссёр, оператор и монтажёр видят свои задачи на Scrum-доске.

Лабораторная работа №1 по дисциплине «Методы и средства проектирования информационных систем»: выбор платформы (Node.js 20 + Express 4.21.2 + EJS 3.1.10) и первая страница в Docker-контейнере.

## Запуск

```bash
docker pull nikitavrazhkin/mispisit-lab1:0.0.1
docker run --rm -p 8080:8080 nikitavrazhkin/mispisit-lab1:0.0.1
```

После запуска открыть http://localhost:8080

## Файлы

- `package.json` — название, версия и зависимости с точными версиями
- `server.js` — сервер Express, отдаёт первую страницу
- `views/index.ejs` — шаблон страницы
- `public/style.css` — стили
- `Dockerfile` — сборка образа
